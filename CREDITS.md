### Excalidraw fonts

The Excalidraw canvas (`src/features/chat/ExcalidrawMcpCanvas.tsx`) uses the
fonts shipped in the `@excalidraw/excalidraw` 0.18.0 npm package (Assistant,
Cascadia Code, Comic Shanns, Excalifont, Liberation Sans, Lilita One, Nunito,
Virgil, Xiaolai). **They are not in this repository**: `pnpm install` downloads
them and `vite.config.ts` copies them into the build so the canvas works
offline. Neither the npm package nor the Excalidraw repository ships their
license texts; upstream, these families are published under the SIL Open Font
License 1.1, except Comic Shanns (MIT). This has not been verified file by file.

## Dependencies compiled into the app

Generated, never written by hand: [third-party/npm.md](third-party/npm.md)
(production npm packages bundled in the front) and
[third-party/rust.md](third-party/rust.md) (crates compiled into `terminus` on
any platform), each with its license texts. Regenerate them with
`node scripts/notices.mjs` after changing `pnpm-lock.yaml` or `Cargo.lock`.

Notable pieces:

- [CodeMirror 6](https://codemirror.net/) (MIT) — the code editor in the file
  view.
- [`@modelcontextprotocol/ext-apps`](https://github.com/modelcontextprotocol/ext-apps)
  and `@modelcontextprotocol/client` (MIT) — the MCP Apps host in the chat.
- `@excalidraw/excalidraw`, React and ReactDOM (MIT) — the Excalidraw canvas.
- [Tauri](https://tauri.app) (Apache-2.0 or MIT) — the desktop shell.

## The engine and the programs it runs

`seldon-runtime` is proprietary software by Danil, distributed separately as a
binary with its own terms (`TERMS.md`) and third-party notices
(`THIRD-PARTY-NOTICES-<platform>.txt`) in each engine release; see
`seldon-runtime.lock`. The programs the engine downloads at runtime (Git, Node.js,
agent CLIs, optional plugins) keep their own licenses and are not part of this
repository.

The draw.io viewer used by the chat is installed by the engine's `drawio`
plugin, not bundled here: [draw.io](https://github.com/jgraph/drawio),
Apache-2.0 © JGraph Ltd.
