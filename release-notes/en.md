Write Typst documents with the preview alongside, as in typst.app, even large ones. The chat shows the work an agent delegates right inside the conversation, and the space files panel tells you what each project takes up and leads to its task.

- **Live Typst.** With the Typst plugin (Settings → Plugins), the eye in the file tree picks the main document and its PDF stays pinned beside any text file of the task. The preview updates as you type, errors are marked in the editor with an option to let the agent fix them, clicking in the code moves the preview there and double-clicking the preview opens that line. "Export PDF" writes `dist/<main>.pdf`. An earlier install of the plugin asks to be updated.
- **Delegated work in the chat.** Tasks an agent creates appear in its conversation with the same card as the sidebar, grouped under "Created tasks". The subtasks button in the top bar filters them and leads back to the coordinator, and the coordinator's row keeps showing work while a subtask is working.
- **Space files.** The panel is compact, groups by project or by task, shows the latest activity and lets you open or empty each task. It measures much faster and no longer gives up saying it couldn't reach the Seldon Plan Host on large folders.
- **AI providers.** In Settings each provider collapses and the active account is clear at a glance.
- **Reorder spaces and workspaces.** Drag them to change their order; the order is kept when you reopen.
- **Copy link.** The menu of a web link in the chat lets you copy it.
- **Chat background.** Terminus keeps a copy of the background you pick; it stays available even if the original is deleted.
- **Fixes.** Chat messages no longer vanish for a moment when a long turn closes, the answer to a side question scrolls inside its panel, a workspace's notice no longer overflows its box, the subtasks indicator no longer shows twice in the composer, and a PDF too large for the preview offers to open in the system app.
